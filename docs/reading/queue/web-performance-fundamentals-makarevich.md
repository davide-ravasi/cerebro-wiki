# What it covers

- Why speed matters and **how to measure** it
- **Initial load** performance, **Core Web Vitals**
- **Performance flame graphs** (Chrome DevTools)
- Rendering patterns: **CSR, SSR, RSC** — measure impact of each
- **Bundle size** investigation, **Suspense**, **React Server Components**
- **Interaction** performance, re-renders, **React Compiler**
- Hands-on with **Vite**, **TanStack**, **Next.js**

~**Two-thirds** general web performance; React as the primary lens for examples.

# Audience (from the book)

Middle–senior **React** developers who can navigate a codebase without basics being explained. Useful for non-React devs comfortable with web fundamentals who want perf depth.
